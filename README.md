# NeWWave website

A responsive single-page project website for **NeWWave — NekRS + OpenFAST + HOS**.

## Files
- `index.html` — page content and inline SVG artwork
- `styles.css` — full responsive styling
- `script.js` — navigation and scroll animations

## Use
Open `index.html` in any modern browser.

## Before publishing
Replace `your.email@mun.ca` in `index.html` with the preferred project contact email.

## Easy hosting options
This folder can be deployed directly to GitHub Pages, Netlify, Vercel, or any standard static host.
